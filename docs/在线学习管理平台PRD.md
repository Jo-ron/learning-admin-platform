# 产品需求文档 PRD - 在线学习管理平台 V1

## 1. 项目概述
### 1.1 项目背景
中小型教培机构普遍缺少轻量化、低成本的教学管理系统，商用SaaS系统功能冗余、价格昂贵、学习成本高。
本项目旨在搭建一套轻量化 B 端教学管理后台，帮助机构管理员统一维护课程、学生数据、监控教学运营数据，解决数据分散、无法可视化统计、运营无数据支撑的问题。

### 1.2 用户角色
V1.0 仅单角色：机构管理员
- 需求：管理课程信息、维护学生档案、查看整体教学运营数据

### 1.3 版本策略（MVP 最小可行产品）
采用迭代式产品设计：
- V1（当前已完成）：跑通核心业务闭环，基础数据管理 + 数据看板
- V2（规划迭代）：选课管理、师资管理、操作日志、数据预警、批量操作、权限细化

## 2. 功能需求（V1 已完成）
### 2.1 登录权限模块
1. 支持管理员账号密码登录
2. 未登录状态强制拦截，自动跳转登录页
3. 全局接口鉴权，保证后台数据安全

### 2.2 数据工作台 Dashboard
1. 四大核心指标：课程总数、学生总数、课程发布率、学生活跃率
2. 所有指标支持 hover 悬浮提示，展示指标统计口径，解决数据理解偏差问题
3. 四类数据图表：选课人数柱状图、七日学习活跃度折线图、学生状态饼图、课程分类饼图
4. 用于管理员快速掌握整体教学运营情况

### 2.3 课程管理模块
1. 课程列表：分页、搜索、多条件筛选、选课人数排序
2. 课程新增、编辑、删除
3. 课程基础状态管理：草稿 / 已发布 / 下架

### 2.4 学生管理模块
1. 学生列表：分页、搜索、班级/状态筛选
2. 学生新增、编辑、删除
3. 支持学生关联选修课程

## 3. 非功能需求
1. 安全性：未登录路由拦截、接口鉴权
2. 易用性：分页加载、条件筛选、二次确认弹窗
3. 可扩展性：业务结构清晰，支持后续迭代选课、师资、日志模块
4. 可维护性：数据结构规范，支持后续数据统计升级

## 4. V2 迭代规划（待开发）
1. 业务增强：独立选课管理、教师管理、操作审计日志
2. 数据增强：数据异常预警、指标时间筛选
3. 体验增强：批量导入导出、数据软删除、完善业务状态约束
