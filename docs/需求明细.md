# 需求明细｜在线学习管理平台 V1
> 配套PRD的功能细节，页面字段、交互、校验规则

## 1. 登录页
1. 字段：用户名（输入框）、密码（密码框）
2. 校验：用户名/密码不能为空；账号密码错误给出toast提示
3. 交互：未登录访问任意后台页面，自动跳转登录；登录成功跳转工作台

## 2. 工作台 Dashboard
1. 统计卡片4个：课程总数 / 学生总数 / 发布率 / 活跃率
2. 交互：hover卡片，弹出悬浮提示框，展示指标统计口径
    - 例：课程发布率 = 已发布课程 ÷ 全部课程
3. 图表：
    - 柱状图：各课程选课人数
    - 折线图：近7日学生活跃趋势
    - 饼图1：学生状态分布
    - 饼图2：课程分类分布
4. 异常：无数据时图表展示空状态提示

## 3. 课程管理列表页
1. 列表字段：课程ID、课程名称、授课老师、课程状态、创建时间、操作（编辑/删除）
2. 筛选&搜索：课程名称搜索，课程状态下拉筛选
3. 分页：每页10条
4. 新增/编辑弹窗字段：课程名称、授课老师、课程简介、课程状态（草稿/已发布/下架）
5. 校验：课程名称不能为空
6. 删除交互：点击删除弹出二次确认，确认后删除

## 4. 学生管理列表页
1. 列表字段：学生ID、学号、学生姓名、班级、学生状态、操作（编辑/删除）
2. 筛选&搜索：姓名搜索、班级筛选
3. 分页：每页10条
4. 新增/编辑弹窗字段：学号、姓名、班级、状态、选修课程（多选关联课程）
5. 校验：学号不可重复、姓名不能为空
6. 删除交互：删除二次确认弹窗

## 通用交互规则
1. 新增/编辑成功：弹出成功提示，自动刷新列表
2. 表单提交：前端基础校验
3. 所有删除操作增加确认弹窗，防止误操作
