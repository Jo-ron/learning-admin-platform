# 在线学习管理平台（B端后台产品）
> 产品经理实战项目，面向培训机构管理员，用于课程、学员管理与学习数据可视化。

## 📌 项目背景
中小型培训机构缺少轻量化教学管理后台，本平台实现学员、课程统一管理，通过数据看板直观监控课程发布率、学员活跃情况，辅助运营决策。

## ✨ 产品功能
1. 身份权限：管理员账号登录，未登录自动拦截跳转登录页
2. 工作台Dashboard：核心指标统计卡片 + 多维度图表（选课人数、学员活跃度等）
3. 课程管理：课程新增、编辑、上下架、查询
4. 学生管理：学员信息维护，学员学习数据查看
5. 学习数据汇总：学习成果统计展示
