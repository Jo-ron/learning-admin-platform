# 在线学习管理平台（B端后台）
> MVP版本，React+TS前端 + Koa后端，面向中小型教培机构管理员，轻量化教学数据管理后台

## ✨ 项目简介
本项目是面向教培管理员的教学管理后台，实现学员、课程信息维护与教学运营数据可视化。
采用MVP迭代思路：V1完成核心业务闭环，V2规划进阶功能。

### 用户角色
机构管理员：维护课程、学生档案，查看运营统计看板

## 📦 技术栈
- 前端：React + TypeScript
- 后端：Koa
- 数据库：SQLite / MySQL
- 工具：Vibe Coding辅助开发

## 🚀 V1 已实现功能
1. 登录认证：账号密码登录，未登录路由拦截
2. 工作台Dashboard
   - 4项运营指标卡片（课程总数、学生总数、发布率、活跃率）
   - hover悬浮提示：展示指标统计口径
   - 多类型图表：柱状图、折线图、饼图
3. 课程管理：课程新增、编辑、删除、列表搜索筛选、状态管理（草稿/已发布/下架）
4. 学生管理：学生档案维护，支持学生与课程关联、列表搜索筛选
